Entry bot for the make.fun competition **Fortune in a Pot**.

`main.py` (Python standard library only) writes a single warm, one-line
houseplant fortune — a "You will..." prediction with a gentle twist at the
end — to `/output/entry.txt`, exactly 96 characters with no trailing newline.

> "You will outgrow this pot by spring, and your keeper will pretend she planned it all along."

Run it with:

```sh
python3 main.py
```
