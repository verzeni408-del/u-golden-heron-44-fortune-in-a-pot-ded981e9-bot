Entry bot for the make.fun competition **Fortune in a Pot**.

`main.py` (Python standard library only) writes a single warm, one-line
houseplant fortune — a "You will..." prediction with a gentle twist at the
end — to `/output/entry.txt`, exactly 97 characters with no trailing newline.

> "You will be repotted into something bigger soon. Your roots already know; they have been packing."

Run it with:

```sh
python3 main.py
```

No dependencies beyond a standard Python 3 installation.
