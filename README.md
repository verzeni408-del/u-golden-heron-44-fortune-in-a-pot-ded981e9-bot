A tiny pot, a quiet plant, and a future it can already feel coming.

This little project holds a single houseplant fortune, written as one line of text. The plant in question is not complaining about its pot — it is already looking forward to the bigger one waiting ahead, roots and all.

The fortune itself reads:

> "You will be repotted into something bigger soon. Your roots already know; they have been packing."

Everything here is kept deliberately small. One script does the whole job, leaning only on the Python standard library, so there is nothing extra to install and nothing to configure before it runs.

When the script finishes, it leaves behind a plain text file holding that fortune on a single line — 97 characters in total, with no newline tucked at the end.

## Running it

From this directory, just run:

```sh
python3 main.py
```

That produces the fortune at `/output/entry.txt`, ready to read. Open it whenever you want a small reminder that growth is already underway, even before anything visible changes.
